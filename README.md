## 结论边界

- LINK 文档使用台服可用职业和传授值；资料页发生冲突时，会在正文标明采用哪一项及原因。
- 联盟神器文档使用台服官方数值；职业条件属性必须以游戏内技能分类和战斗分析确认是否转化为实际输出。
- 减 CD 帽文档结合官方机制、职业攻略和高端玩家配装分布，不是统一装备条件下的全职业 DPS 模拟。
- 灵魂武器升级费用已按官方逐级表重新验算；版本更新后仍应以游戏内显示为准。
- 文档中的日期是资料复核日期，不代表结论永久有效。平衡更新、HEXA 技能和首领环境变化都可能改变推荐。
